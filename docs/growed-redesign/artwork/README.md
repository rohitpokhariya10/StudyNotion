# Footer artwork source

`generate-footer-landscape.mjs` is the recovered generator for the approved landscape. It imports the authored bird outlines and flock from `footer-birds.mjs`. From the repository root:

```sh
node docs/growed-redesign/artwork/generate-footer-landscape.mjs
```

An optional output filename generates a comparison file without overwriting the asset. The default output is `apps/web/src/shared/assets/editorial/footer-landscape.svg`.

The recovery was verified against the approved SVG before editing. The bird correction preserves all generated bytes outside the bird group. Landscape generation retains its original seeded random numbers; the flock uses 29 explicit placements, four poses and three blue tones. No animation or external asset is used.

Each pose is one closed perimeter with an explicit nonzero fill rule on its parent. Wings, body, head/beak and tapered tail meet along that perimeter; there are no overlapping subpaths or holes. Change the paths/placements in `footer-birds.mjs`, then regenerate. Do not edit just the generated SVG.

Verification: [shape checks](../verification/footer-bird-shapes.json), [enlarged poses](../screenshots/footer-bird-poses.png), [actual desktop footer](../screenshots/prahit-birds-localhost-footer-1440.png), [actual mobile footer](../screenshots/prahit-birds-localhost-footer-390.png). The source stays deterministic; regeneration was compared byte-for-byte after the final correction.
