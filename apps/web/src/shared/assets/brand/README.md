# Prahit official artwork

Source: user-supplied `best_1.png`, archived unchanged in `original/best_1.png`.

- Original size: 1254 × 1254; original SHA-256: `0bf8deba6943219f0f498e1848d07ec02a22c756dd386738c0ff5e935d757cc4`.
- Logo crop: x=220, y=325, width=790, height=620. Includes the entire cream outline, stars, book, blue interior and background with breathing room on every side. No transparency removal, tracing, font recreation or generated imagery.
- `prahit-logo.webp`: 632 × 496, high-quality WebP (0.94); exact original proportions. Shared BrandLogo uses it at 60px height in desktop navigation and 48px in mobile navigation; larger variants serve auth/contact/footer.
- Public `logo.png`: 395 × 310 copy of the same full mark, retained at the existing public URL for compatibility and relative social-preview metadata.
- Compact icon source: book-only rectangle x=579, y=642, width=142, height=80. Neighboring letters were excluded. Its original cream pages and blue spine remain; the source's blue corner colour fills the square padding. `favicon-{16,32}.png`, `favicon.ico` (16/32 PNG entries), `apple-touch-icon.png` (180), `logo192.png`, `logo512.png`, and the compatibility `icon.svg` wrapper use this detail. The 512px icon has mask-safe padding.

Crops were performed with macOS `sips`; proportional resampling/encoding and square icon padding used the browser Canvas API. The original source is never imported into the bundle. The blue background is deliberately retained. Historical unused Logo-Full/Small assets and the frozen checkout-specific `rzp_logo.png` are not BrandLogo inputs.
